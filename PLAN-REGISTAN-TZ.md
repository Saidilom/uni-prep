# План доработки проекта Registan по ТЗ

> Дата аудита: 30 июля 2026  
> Источник требований: `tz`  
> Текущий проект: Next.js 14 + Firebase + Firestore (бренд **UniPrep**)

---

## 1. Краткий вывод

Сейчас проект — **образовательная платформа по предметам** (учебники → темы → тренировочные тесты, классы учителей, достижения, медали).  
По ТЗ нужна **другая платформа** — подготовка к Национальному сертификату для учебного центра **Registan** с двумя ключевыми модулями:

1. **Вступительное тестирование (Placement Test)**
2. **Mock-тесты** (бесплатные для учеников Registan + платные для всех)

Большая часть текущего функционала **не входит в первый этап** ТЗ и должна быть либо скрыта, либо вынесена за рамки MVP.

## 12. Этап 8 — Тестирование и деплой

### 12.1. Сценарии ручного тестирования

**Placement:**
1. Сканировать QR → зарегистрироваться по телефону
2. Убедиться, что пользователь появился в `/admin/users`
3. Админ назначает Placement-тест
4. Ученик проходит → результаты в `/admin/placement/results`

**Mock (Registan):**
1. Админ выдаёт статус «Ученик Registan»
2. Ученик видит бесплатные Mock → проходит → результат в админке

**Mock (платный):**
1. Обычный пользователь покупает Mock
2. Оплата проходит → тест открывается
3. Запись в `/admin/payments`
